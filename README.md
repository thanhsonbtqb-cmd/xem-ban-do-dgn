# Xem bản đồ địa chính DGN

Chương trình xem tờ bản đồ địa chính MicroStation DGN (V7, V8) trên điện thoại và máy tính, chạy hoàn toàn trên máy (file bản đồ không được gửi đi đâu).

- Mở file `.dgn`, `.zip`, `.rar` (nhiều tờ), tìm thửa, xem thông tin và toạ độ đỉnh thửa (VN-2000)
- 🎯 Xem đối tượng thuộc level nào, 📏 đo, ◐ đổi nền
- 📍 Xem tâm thửa trên Google Maps (chuyển VN-2000 → WGS84 bằng 7 tham số)
- Chạy offline sau lần mở đầu, tự mở lại các tờ đã xem

Trên iPhone: mở trang bằng Safari > Chia sẻ > "Thêm vào MH chính".
